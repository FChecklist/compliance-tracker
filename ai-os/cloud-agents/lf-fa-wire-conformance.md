## Why this package exists
The laptop sync engine was built and tested ONLY against a fake sync server written from the contract text. An independent review ran the real client against the real backend handler on a real Postgres (PGlite) and found that the fake had been hiding real defects: **every real sync would end in `user_mismatch`** (the client compares the sign-in id with the VERIDIAN user id, two different strings), the BOQ screen filters out every real row (the server sends snake_case rows, the screen expects a camelCase shape), a 200-id pull is refused (413) and wedges a project forever, and more. The reviewer's harness is `ai-os/cloud-agents/review-findings/lf-wire.integration.test.ts.txt` (40 tests named `[W01]`..: 20 pass, 20 fail at review time; the failing ones are the defects). Your job is to make this class of defect impossible to hide again and to fix the client-owned ones.
