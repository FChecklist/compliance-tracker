# DPDP job library snapshot

`dpdp-library-0.2-wo010.json` is a direct export of `dpdp.obligation_template`
for `library_version` `0.2-wo010` (59 jobs, products `firm` and `institution`,
parts 1-7), taken 2026-09-22 from the live project. It is the input for the
WO-DPDP-012 §5 job-page generator ("one public page per job, generated from
the library data, never retyped").

It is a snapshot, not the source of truth: when the lawyer-reviewed library
replaces `0.2-wo010`, re-export and regenerate (the long-term plan is a
build-time RPC read so the pages regenerate automatically). Nothing in this
file is personal data -- it is the public job catalogue.
